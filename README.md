# ITStorm — Веб-студия

Сайт веб-студии, реализованный с разделением на **frontend** (Angular) и **backend**.  
Проект состоит из двух отдельных приложений, которые работают совместно.

---
## Технологии

Frontend:
1) Angular.
2) TypeScript, RxJs.
3) HTML / CSS / SCSS.
4) Angular CLI.

---
## Возможности проекта

1) Полноценный сайт веб-студии.
2) Клиентская часть на Angular.
3) Серверная часть — REST API.
4) Разделение фронтенда и бэкенда для лучшей архитектуры.
5) Возможность развёртывания как отдельных частей, так и всё вместе.
